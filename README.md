## Structure

```
css/style.css          all styling (colors are CSS variables at the top)
js/main.js             animations, slideshow, document viewer
assets/img/gallery/    slideshow photos
assets/posters/        research posters (PDF + preview image)
assets/artifacts/      Key Insight artifacts (PDF + preview image)
assets/pages/          page-by-page images used by the in-site document viewer
assets/Tiffany-Yu-Resume.pdf
```

Plain HTML/CSS/JS — no build step. Edit a file, commit, and push; GitHub Pages redeploys automatically.
